A Python program (standard library only, deterministic, no network) that writes a single one-line office joke to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

The joke:

> I muted the all-hands meeting and read the recap AI wrote, which muted me back by summarizing my job as 'attends meetings.'

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
